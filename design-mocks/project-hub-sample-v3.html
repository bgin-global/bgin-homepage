PQC Migration

Preparing blockchain systems for post-quantum cryptography: crypto agility, migration playbooks, and neutral evaluation infrastructure — coordinated internationally through BGIN.

Discuss on Discourse GDC26 session

At a glance

Working Group
IKP — IAM, Key Management and Privacy
Latest document
Block 14 MR: Crypto Agility and PQC Migration
Next milestone
GDC26 (2–3 Sep, Geneva) → Block 15 (15–16 Oct, DC)
Primary deliverables
Migration guidance · Crypto-agility patterns · Testbed coordination

Overview

This project examines how blockchain systems can migrate to post-quantum cryptography without service disruption. Work covers NIST PQC standards status, crypto-agility design patterns, hybrid transition approaches, and migration strategies for key management, signatures, and identity credentials.

Expected deliverables

  • Practical guidance on PQC migration for blockchain stacks
  • Crypto-agility architecture patterns (hybrid / algorithm agility)
  • Inputs to neutral evaluation and measurement (testbed coordination)
  • Session outcomes and meeting reports from Block meetings

Current status

Dedicated sessions ran at Block 13 and Block 14. Outreach to researchers and ecosystem partners is underway for Block 15 participation and related evaluation discussions. Public materials below reflect the latest shared drafts and reports.

Overview

Despite industry progress, cybersecurity incidents remain common in crypto. This project develops a robust international information-sharing framework, drawing lessons from traditional finance and existing ISAC models, tailored to blockchain operators, vendors, and regulators.

Expected deliverables

Security Target & Protection Profile (ST/PP)

Developing Security Target (ST) and Protection Profile (PP) standards for blockchain systems, adapting Common Criteria–aligned evaluation methods to wallets, smart contracts, and cryptographic key lifecycle management.

Discuss on Discourse GDC26 session

At a glance

Working Group
Cyber Security
Latest document
Block 14 MR: Security Target and Protection Profile
Next milestone
GDC26 (2–3 Sep) → Block 15 (Oct)
Primary deliverables
Wallet ST · PP methodology · certification pathway notes

Overview

This project adapts established Security Target and Protection Profile methodologies (aligned with Common Criteria and industry practice) to the security requirements of decentralised architectures. Scope includes defining evaluation targets for blockchain components, wallet security targets, smart contract security profiles, and cryptographic key lifecycle management.

Expected deliverables

  • Draft Security Targets for priority blockchain components (starting with wallets / key management)
  • Protection Profile development methodology notes for crypto systems
  • Smart contract security profile considerations
  • Certification pathway options and open questions for multi-stakeholder review
  • Meeting reports from Block sessions documenting consensus and next steps

Current status

Work has progressed through Block 12 (Development of ST/PP), Block 13, and Block 14 sessions moderated with Cyber Security WG leadership. The project remains in draft: Common Criteria relevance, component-level targets, and certification pathways are under active discussion ahead of Block 15.
